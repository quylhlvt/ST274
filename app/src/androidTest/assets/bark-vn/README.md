Vietnamese speech fixtures generated locally with macOS say (Linh, rate 140).
Each file contains the word in its filename: gau = gâu, go = gô, mo = mõ,
vang = vàng, giang = giàng. PCM16 little-endian, mono, 16,000 Hz,
converted using afconvert. No user microphone recordings are included.

These fixtures check this bundled model and synthetic voice only; they do
not establish accuracy for all speakers or background noise.
